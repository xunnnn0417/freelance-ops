# QA Checklist

## Data / spreadsheet
- [ ] Required columns are present and in agreed order.
- [ ] No accidental duplicate records.
- [ ] URLs/handles/phones/IDs use consistent formatting.
- [ ] Formulas calculate correctly and do not contain broken references.
- [ ] Unverified values are blank/flagged instead of guessed.
- [ ] Sample spot-checks match primary/credible sources.
- [ ] Filters/sorts did not misalign rows.
- [ ] Workbook opens correctly and sheet names are clear.

## Research
- [ ] Entity match is correct; no same-name mixups.
- [ ] Source is traceable where the task requires it.
- [ ] Recency requirement is satisfied.
- [ ] Contact/person role actually matches client criteria.
- [ ] Verification status is recorded honestly.

## Code / automation
- [ ] Script runs on a clean sample.
- [ ] Inputs/outputs are documented.
- [ ] Failure cases are handled or clearly documented.
- [ ] No secrets/API keys/private client data are committed.
- [ ] Third-party licenses are compatible and recorded.

## Client-facing impression
- [ ] File names look professional.
- [ ] No placeholder text remains.
- [ ] No unsupported claims.
- [ ] Deliverable looks intentionally formatted, not like raw AI output.
- [ ] Delivery message states what was actually checked.
