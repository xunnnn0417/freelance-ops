## Safety / fit
- No public red flags such as upfront payment, crypto/gift cards, off-platform payment, Telegram/WhatsApp migration, suspicious download, or sensitive-data demand.
- Strong hire count and meaningful spend are positive trust signals, but 50+ proposals make competition high.
- Deliverability: ~95% for the public scope using Excel/Google Sheets + Python/openpyxl QA where useful.
- Main blocker: Upwork freelancer profile/application readiness and any Connects cost. Do not purchase Connects automatically.

## Positioning
Pitch accuracy + lightweight QA, not generic 'I am a hard worker'. Offer a small sample on the client's structure and explain duplicate/completeness checks.

## Proposal draft
Hi — I can handle the spreadsheet updates and record cleanup with a simple QA pass built into the workflow, so the final file is consistent rather than just manually entered.

For this type of project I check required fields, formatting consistency, obvious duplicates, and unclear/missing values before delivery. I’m comfortable working in Excel or Google Sheets and can follow an existing structure exactly.

If helpful, I can complete a small sample from your source data first so you can verify the format and accuracy before I continue with the full file.
