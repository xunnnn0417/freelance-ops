# Reusable Tools

Store only reusable, non-client-private scripts or references here.

Before integrating a third-party repository/library/template:
1. Confirm it materially improves accuracy, QA, automation, formatting, presentation, or reliability.
2. Check license. Prefer MIT / Apache-2.0 / BSD-style licenses.
3. For GPL/AGPL or unclear licenses, record obligations and do not mix into client deliverables until compatibility is understood.
4. Never present third-party work as original.
5. Record source repository, version/commit when practical, license, purpose, and modifications.

Current reusable assets exist outside this repository from earlier cases (spreadsheet templates and QA/enrichment scripts). Only copy them here after confirming they contain no private/client data and their public release is intentional.
